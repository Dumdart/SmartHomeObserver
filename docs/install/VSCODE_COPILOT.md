# Connect TopicGate to VS Code or GitHub Copilot CLI

First [install TopicGate](OS_INSTALL.md), run `topicgate-gui`, and configure and connect a broker in **TopicGate Desktop**. Install your chosen host first.

A **plugin** loads TopicGate skills and MCP configuration. **MCP-only** connects the server without those skills. Choose one path per host; the default is **read-only mode**.

## VS Code plugin integration (recommended)

Merge these settings into VS Code's user `settings.json`, preserving existing marketplace entries:

```json
{
  "chat.plugins.enabled": true,
  "chat.plugins.marketplaces": ["Dumdart/TopicGate"]
}
```

In Extensions, search for `@agentPlugins` and install TopicGate. Start a new chat.
The plugin requires the installed `topicgate` executable on PATH and launches it in read-only mode. See [VS Code's plugin documentation](https://code.visualstudio.com/docs/agent-customization/agent-plugins) if these settings are unavailable in your version or managed by your organization.

### VS Code MCP-only alternative

Merge this into `.vscode/mcp.json` in your workspace. For personal configuration, use **MCP: Open User Configuration** instead.

```json
{
  "servers": {
    "topicgate": {
      "type": "stdio",
      "command": "topicgate",
      "args": ["--mode", "read-only"]
    }
  }
}
```

Use **MCP: List Servers** to start the server and review the trust prompt. VS Code uses `servers`, not the `mcpServers` wrapper generated by Desktop. Copy the inner server's command, arguments, and environment if you need Desktop's resolved executable or custom data directory. See [VS Code's MCP documentation](https://code.visualstudio.com/docs/agent-customization/mcp-servers).

## GitHub Copilot CLI plugin integration (recommended)

With `copilot` installed, run:

```console
topicgate-cli integration install copilot
```

The helper installs or updates the plugin and manages the `topicgate` MCP entry. It can reuse a plugin-provided server in read-only mode; otherwise it writes a user entry. Alternatively, install the plugin manually:

```console
copilot plugin marketplace add Dumdart/TopicGate
copilot plugin install topicgate@topicgate
```

Restart Copilot CLI and start a new session after changes.

### Copilot CLI MCP-only alternative

Use this instead of the plugin; `.vscode/mcp.json` is for VS Code, not Copilot CLI:

```console
copilot mcp add topicgate -- topicgate --mode read-only
```

If the executable is not found, use the command, arguments, and environment from Desktop's **Help → MCP setup...**. See [executable recovery](UPGRADE_AND_RECOVERY.md#executable-not-found).

## Control mode and maintenance

For Copilot CLI, explicitly opt in with:

```console
topicgate-cli integration install copilot --mode control
```

For VS Code or an MCP-only integration, change the existing server's arguments to `["--mode", "control"]`. If a plugin also supplies a server, disable its MCP server before starting the manual control entry. In VS Code use **MCP: List Servers** to select and disable it. Restart the MCP server and start a new chat/session; verify the exposed tools.

Control mode is only for trusted environments. Read [Control mode and health](CONTROL_AND_HEALTH.md) for capabilities, publishing confirmation, and local credential handling.

Maintain the Copilot CLI plugin integration with:

```console
topicgate-cli integration status copilot
topicgate-cli integration repair copilot
topicgate-cli integration uninstall copilot
```

These commands do not configure VS Code. See [upgrades and recovery](UPGRADE_AND_RECOVERY.md) for repair semantics.
